# Roadmap del proyecto

El proyecto avanzará por fases pequeñas. Cada fase debe revisarse y aprobarse antes de comenzar la siguiente.

| Fase | Alcance |
|---:|---|
| 0 | Estructura inicial del repositorio |
| 1 | Documentación técnica inicial |
| 2 | Diseño del modelo de datos |
| 3 | Inicialización del backend Spring Boot |
| 4 | Configuración de MySQL |
| 5 | Usuarios, roles y permisos |
| 6 | Autenticación JWT |
| 7 | Áreas, cargos y sedes |
| 8 | Gestión de empleados |
| 9 | Horarios y turnos |
| 10 | Registro básico de asistencia |
| 11 | Reglas de tardanzas, salidas e inasistencias |
| 12 | Incidencias y justificaciones |
| 13 | Auditoría |
| 14 | Reportes del backend |
| 15 | Inicialización de Angular |
| 16 | Inicio de sesión y seguridad en Angular |
| 17 | Layout y navegación en Angular |
| 18 | Módulos administrativos en Angular |
| 19 | Gestión de asistencia en Angular |
| 20 | Reportes en Angular |
| 21 | Inicialización de Flutter |
| 22 | Autenticación en Flutter |
| 23 | Inicio del empleado |
| 24 | Registro de asistencia móvil |
| 25 | Historial y horarios en móvil |
| 26 | Incidencias en móvil |
| 27 | Seguridad avanzada de asistencia |
| 28 | Geolocalización y geocerca |
| 29 | QR dinámico |
| 30 | Auditoría avanzada |
| 31 | Pruebas |
| 32 | Integración completa |
| 33 | Preparación del piloto |

Este roadmap puede ajustarse conforme aparezcan requisitos validados, dejando constancia de los cambios relevantes.
